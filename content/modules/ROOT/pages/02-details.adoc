= Prerequisites and Environment
:navtitle: Prerequisites and Environment

== What you need

|===
| If you are… | You need

| Every participant
| The Showroom terminal tab (`oc` is already logged in) and the OpenShift
Console tab.

| Facilitator
| A cluster-admin login to each participant cluster, to provision and verify
the lab (see xref:92-facilitator-guide.adoc[Facilitator Guide]).
|===

Provided by the facilitator:

* A dedicated {ocp_version} cluster per participant, using the default
  OVN-Kubernetes network plugin, with the lab deployed through OpenShift
  GitOps.
* The `{lab_namespace}` namespace with the `{model_api}`, `{allowed_client}`,
  and `{blocked_client}` Deployments running and no NetworkPolicy in it.

== Verify the tools

[source,bash,role="execute",subs="attributes+"]
----
oc version --client
----

Expected result: a `Client Version:` line, which shows the `oc` CLI is on
the terminal's path.

== Run the pre-flight check

Run these in the Showroom terminal:

[source,bash,role="execute",subs="attributes+"]
----
oc whoami
oc get namespace {lab_namespace}
oc auth can-i get pods -n {lab_namespace}
oc auth can-i create pods --subresource=exec -n {lab_namespace}
oc auth can-i create networkpolicies.networking.k8s.io -n {lab_namespace}
oc auth can-i delete networkpolicies.networking.k8s.io -n {lab_namespace}
----

Expected result: `oc whoami` prints
`system:serviceaccount:{showroom_namespace}:showroom`, the namespace is
`Active`, and every `auth can-i` line prints `yes`. Those are the only
permissions the exercises use.
